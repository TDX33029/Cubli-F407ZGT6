# Cubli 三轴无刷电机联调上位机 (PyQt5)

专门针对 **Cubli-F407ZGT6** 三轴无刷电机联调设计的专业上位机控制与数据监控软件。

---

## 1. 硬件接线与通信参数

| 信号名称 | MCU 物理引脚 | USB-TTL 串口线 | 说明 |
| :--- | :--- | :--- | :--- |
| **USART2_TX** | **PD5** | **RXD** | 下位机遥测数据与指令应答发送端 |
| **USART2_RX** | **PD6** | **TXD** | 上位机调速指令接收端 |
| **GND** | **GND** | **GND** | 必须共地 |

### 陀螺仪传感器引脚定义
- **LSM6DSRTR (主用，默认开启)**:
  - **PB12**: CS (片选，板载 3.3V 上拉 R49)
  - **PB13**: SPI2_SCK
  - **PB14**: SPI2_MISO
  - **PB15**: SPI2_MOSI
- **MPU-6050 (备用，默认关闭)**:
  - **PB10**: SCL (软件模拟 I2C)
  - **PB11**: SDA (软件模拟 I2C)
  - AD0 接地，地址 0x68

- **波特率**：`115200 bps`
- **数据位**：8
- **停止位**：1
- **校验位**：无 (None)
- **流控**：无 (None)

## 3. 主要功能说明

### 3.1 三轴电机独立控制 (M1 / M2 / M3)
- **PWM 映射**：
  - **电机 1 (M1)**: TIM1 (PE9/PE11/PE13), 驱动使能引脚 **PD0**
  - **电机 2 (M2)**: TIM3 (PA6/PA7/PB0), 驱动使能引脚 **PD1**
  - **电机 3 (M3)**: TIM4 (PD12/PD13/PD14), 驱动使能引脚 **PD2**
- **连续无级调速**：
  - 支持 **-30.0 rad/s 到 +30.0 rad/s** 连续调节。
  - 双向滑动条 + 精确数值输入框 (`QDoubleSpinBox`)，带有 50ms 防抖合并机制。
- **单位双显**：
  - 界面同时显示电机的角速度 `rad/s` 与机械转速 `RPM`（$\text{RPM} = \text{rad/s} \times 9.549$）。
- **快捷控制**：
  - 具备 `[-10]`、`[-5]`、`[0 停]`、`[+5]`、`[+10]` 快速挡位。
  - `[反转]` 按钮：快速取负当前速度，切换旋转方向。
  - `[驱动使能]` 复选框：独立控制对应 DRV8313 芯片的使能状态（失能时电机进入高阻滑行状态）。

### 3.2 三轴联动与同步调速
- **Master / Sync 面板**：一键设置三路电机的目标转速，适用于三轴协同旋转与测试。
- **全部归零 (Stop All)**：平稳将三路电机转速降为 0，驱动保持使能（电磁定子主动抱死）。
- **紧急停止 (Emergency Stop - ESTOP)**：
  - 触发红色高亮大按钮后，三电机目标转速瞬间置零，同时向 DRV8313 发送硬件失能信号，关闭所有 PWM 输出，确保人身与设备安全。

### 3.3 参数配置与保护限制
- **相电压限制 (Vq limit)**：
  - 可在 `0.5V ~ 6.0V` 安全区间内动态调节 SimpleFOC 矢量电压上限（默认 `2.5V`）。
- **速度限制 (Velocity limit)**：
  - 可动态调节最大允许角速度（默认 `20.0 rad/s`）。
- **遥测流开关**：
  - 可随时开启或关闭下位机 20Hz 高频遥测输出。

### 3.4 三维姿态立方体 (Cubli 3D Display)
- **实时姿态同步**：基于内置互补滤波算法，将 LSM6DSRTR 六轴陀螺仪与重力加速度计数据融合为机体欧拉角（Roll / Pitch / Yaw）。
- **默认方向**：开机与静止放置时**默认水平朝上**（+Z 轴朝上，Roll=0°, Pitch=0°）。
- **空间面与动量轮映射**：
  - 顶面 (+Z, 蓝色)：标有 `TOP / M3`，绘制电机 3 动量轮；
  - 前面 (+Y, 橙色)：标有 `FRONT / M2`，绘制电机 2 动量轮；
  - 右面 (+X, 青色)：标有 `RIGHT / M1`，绘制电机 1 动量轮；
  - 底面 (-Z) 与侧面：带有空间投影地面网格与立体光照着色。
- **动态飞轮旋转动画**：立方体上的动量轮辐条随电机实际转速动态旋转。
- **空间交互**：鼠标左键按住拖拽可任意旋转观察视角，双击任意位置恢复默认正等测视角；顶部提供 `[姿态归零]` 按钮。

### 3.5 实时动态转速波形 (pyqtgraph)
- **平滑滚动时间窗**：采用示波器式 10 秒固定滑动时间窗，彻底解决 autoRange 失效导致曲线跑出视口的问题。
- **防塌陷量程机制**：即使三轴电机处于静止状态（0 rad/s），也保有基准 Y 轴范围并配有虚线零位基准线。
- **加粗高对比线条**：青色 (M1)、橙色 (M2)、洋红 (M3) 三色分明，实时反映三轴转速动态响应。

### 3.7 MT6701 速度闭环控制与电角度标定
- **闭环模式切换**：支持开环速度模式与闭环速度模式一键热切换（`MODE 0` / `MODE 1`）。
- **电角度自动标定**：下发 `ALIGN` 指令，固件依次激励 M1/M2/M3 进行零位和正反向自识别。
- **PID 参数在线微调**：界面提供 P / I / D 在线调整并支持一键下发热生效（`PID <P> <I> [D]`）。
- **实测转速与设定双线对比**：图表中目标设定为虚线、实测转速为高亮实线，直观监控超调量、调节时间与稳态误差。

## 4. 下位机通信协议速查

所有指令均以 `\r\n` 结尾（上位机会自动附加）：

| 指令格式 | 示例 | 功能说明 | 固件应答 |
| :--- | :--- | :--- | :--- |
| `M <v1> <v2> <v3>` | `M 5.0 -3.2 0.0` | 同时设置 M1, M2, M3 的目标转速 (rad/s) | `OK M1:5.00,M2:-3.20,M3:0.00` |
| `M1 <val>` | `M1 8.5` | 设置 M1 单独目标转速 | `OK M1:8.50` |
| `M2 <val>` | `M2 -4.0` | 设置 M2 单独目标转速 | `OK M2:-4.00` |
| `M3 <val>` | `M3 6.28` | 设置 M3 单独目标转速 | `OK M3:6.28` |
| `STOP` 或 `S` | `STOP` | 三电机速度瞬时归零 | `OK STOP` |
| `EN <e1> <e2> <e3>` | `EN 1 1 1` | 分别使能(1)或失能(0)三路 DRV8313 驱动 | `OK EN:111` |
| `EN1 <0/1>` | `EN1 0` | 单独设置 M1 使能/失能 | `OK EN1:0` |
| `MODE <0/1>` | `MODE 1` | 切换开环模式(0)或速度闭环模式(1) | `OK MODE:1 (Closed-loop Speed)` |
| `ALIGN` 或 `CALIB` | `ALIGN` | 触发三轴无刷电机电角度零位自动对齐标定 | `OK ALIGN` |
| `PID <P> <I> [D]` | `PID 0.2 1.2 0.001` | 在线设置三轴速度环 PID 控制器增益 | `OK ALL PID: ...` |
| `PID1/2/3 <P> <I> [D]` | `PID1 0.25 1.5 0.0` | 单独设置某轴速度环 PID 增益 | `OK PID1: ...` |
| `U <voltage>` | `U 2.8` | 调整相电压限制 `voltage_limit` (0.1 ~ 6.0V) | `OK Vq:2.80` |
| `L <limit>` | `L 25.0` | 调整速度上限 `velocity_limit` | `OK Vlim:25.00` |
| `TELE <0/1>` | `TELE 1` | 开启/关闭下位机 20Hz 周期状态遥测报文 | `OK TELE:1` |
| `IMU` | `IMU` | 查询当前六轴陀螺仪与加速度计实时数据与器件ID | 打印 IMU 详细状态 |
| `HALL` 或 `ENC` | `HALL` | 查询三轴电机霍尔/磁编码器当前 14-bit 原始值、角度与实测转速 | 打印三轴编码器状态 |
| `SENSOR <1/2>` | `SENSOR 1` | 切换活动传感器（1: LSM6DSRTR, 2: MPU-6050） | `OK SENSOR:1 online=1` |
| `?` 或 `H` | `?` | 打印固件帮助信息与当前电机状态 | 打印帮助信息 |

### 遥测报文结构
固件以 20Hz~40Hz 频率通过 USART2 上报格式如下：
```text
$TELE,M1:%.2f,M2:%.2f,M3:%.2f,Vq:%.2f,EN:%d%d%d,A1:%.2f,A2:%.2f,A3:%.2f,Gx:%.1f,Gy:%.1f,Gz:%.1f,Ax:%.2f,Ay:%.2f,Az:%.2f,H1:%.1f,H2:%.1f,H3:%.1f,S1:%.2f,S2:%.2f,S3:%.2f#\r\n
```
其中 `S1, S2, S3` 为三个 MT6701 磁编码器滤波解算得到的实际转速反馈值（单位：$\text{rad/s}$）。
