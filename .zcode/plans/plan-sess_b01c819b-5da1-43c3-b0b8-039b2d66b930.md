# 方案设计：移除上电自检、新增上位机自检按钮与全操作安全互锁

## 一、需求变更与核心目标

根据用户要求：
1. **移除原来的上电自动检测**：单片机上电开机时不自动旋转电机、不自动执行开环自检，保持完全静止待机，避免上电意外动作。
2. **上位机新增检测按钮**：在上位机监控界面最显著位置添加“硬件自检与安全互锁”卡片，包含【🔍 开始硬件自检 (TEST)】按钮及自检进度/状态指示。
3. **任何操作开始前必须先执行检测（安全互锁机制）**：
   - 上电与连接串口后，系统默认处于“未自检锁定状态”；
   - 所有的电机速度调节（滑条、输入框、预设按键、反转）、驱动使能开关、三轴同步联动、闭环模式切换、零位校准、参数设定，以及终端控制指令均被拦截/禁用；
   - 唯独保留**【紧急停止 [ESTOP]】**按键始终可用，满足最高工业安全标准；
   - 只有当自检执行完毕且**全部电机与霍尔编码器均检测通过**后，上位机才自动解锁所有电机操作控件。
4. **检测内容与结果展示**：
   - 检测三轴无刷电机（DRV8313 #1/2/3）与对应的 MT6701 霍尔/磁编码器（I2C1/2/3）；
   - 检测 I2C 总线通信成功率（判断物理接线、上拉电阻与芯片通信是否正常）；
   - 检测低速开环驱动下的实际多圈解包绝对旋转角位移（判断电机相线、驱动力矩、磁钢极性与磁感应是否正常）；
   - 自检完成后在上位机界面上直观展示：整体状态徽章、M1/M2/M3 各轴状态（PASS / FAIL）、通信率百分比、累计旋转角度，并在失败时显示针对性排查指引。

## 二、详细技术架构与实现方案

### 1. 单片机固件端改进 (`Core/Src/main.c`)
- **移除上电自测调用**：
  - 从 `main()` 函数中移除上电自动执行的 `Motor_Encoder_OpenLoop_SelfTest()` 以及 5 秒阻塞延时，使单片机上电后以最快速度完成外设初始化并安全静止就绪，静候上位机指令。
- **自检函数协议升级 (`Motor_Encoder_OpenLoop_SelfTest`)**：
  - 增加标准化、结构化报文输出，便于上位机 100% 可靠解析：
    - 开始单轴测试时上报步骤：`$TEST_STEP,M1#`, `$TEST_STEP,M2#`, `$TEST_STEP,M3#`
    - 测试结束时输出结构化总结报文：
      `$TEST_REPORT,M1:PASS:100:432.1,M2:PASS:100:428.9,M3:PASS:100:435.0,ALL:PASS#`
      （或包含异常代码 `FAIL_I2C` / `FAIL_STALL` 及 `ALL:FAIL`）
    - 保留原有的 ASCII 诊断明细表格供串口助手用户直接查阅。
  - 自检全部通过后，顺畅执行电角度零位对齐 `Motor_alignAll()`，确保后续闭环调速立刻可用。

### 2. 上位机端协议解析升级 (`UpperComputer/main.py` -> `SerialWorker`)
- 新增 `sig_test_step = pyqtSignal(str)`（测试步骤信号，参数为 "M1" / "M2" / "M3"）。
- 新增 `sig_test_report = pyqtSignal(dict)`（测试结果字典信号）。
- 在 `_process_received_line` 中加入正则捕获：
  - `TEST_STEP_PATTERN = re.compile(r'\$TEST_STEP,(M[123])#')`
  - `TEST_REPORT_PATTERN = re.compile(r'\$TEST_REPORT,M1:([A-Za-z0-9_()]+):(\d+):([0-9.-]+),M2:([A-Za-z0-9_()]+):(\d+):([0-9.-]+),M3:([A-Za-z0-9_()]+):(\d+):([0-9.-]+),ALL:(PASS|FAIL)#')`
  - 同时具备兼容回退机制：若固件输出 ASCII 汇总行（如 `ALL 3 MOTORS & ENCODERS ARE HEALTHY`），亦可无缝识别。

### 3. 上位机安全互锁组件设计 (`SelfTestCard` & Interlock Logic)
- **UI 布局设计**：
  - 放置于左侧控制面板最顶端（`self.card_m1` 正上方），进入软件映入眼帘。
  - **顶部大号状态徽章**：
    - 初始/未连接：`[串口未连接 - 控制锁定]`（灰 `#94a3b8`）
    - 已连接/未自检：`⚠️ 待自检 - 电机控制已锁定`（橙黄 `#f59e0b`，暗黄底色 `#291e0a`）
    - 检测进行中：`🔄 自检中... (正在低速测试 M1/M2/M3 及霍尔编码器)`（天蓝 `#38bdf8`）
    - 自检全部通过：`✅ 自检通过 - 3轴硬件正常已解锁`（翡翠绿 `#34d399`，暗绿底色 `#064e3b`）
    - 存在故障：`❌ 自检失败 - 存在硬件异常，保持控制锁定`（暗红 `#f87171`，深红底色 `#450a0a`）
  - **操作按钮**：
    - `btn_self_test = QPushButton("🔍 开始硬件自检 (TEST)")`（高 32px，高亮工控按钮，自检中自动禁用防止重复触发）。
  - **3 轴明细状态网格**：
    - `M1 (TIM1/I2C1)`：`[待检测]` / `[正常 PASS]` / `[异常 FAIL]` | `通信率: -- | 旋转角: --`
    - `M2 (TIM3/I2C2)`：`[待检测]` / `[正常 PASS]` / `[异常 FAIL]` | `通信率: -- | 旋转角: --`
    - `M3 (TIM4/I2C3)`：`[待检测]` / `[正常 PASS]` / `[异常 FAIL]` | `通信率: -- | 旋转角: --`
  - **诊断提示栏**：动态显示自检进度或故障排查指引（如检查 I2C 上拉/电机连线/磁铁间距）。

### 4. 严密的动作拦截与控制互锁机制
- **状态变量**：`self.self_test_passed = False`
- **控件级锁定 (`set_motor_controls_locked(True)`)**：
  - 锁定：M1/M2/M3 卡片的所有主动输入控件（转速滑条、SpinBox、使能勾选框、反转按钮、预设按钮）；
  - 锁定：三轴联动同步卡片（`sync_group`）；
  - 锁定：闭环与标定卡片（`cl_group`）；
  - 锁定：相电压上限/速度上限设定按钮；
  - 锁定：一键停止全部按钮（`btn_stop_all`）；
  - **例外放行**：【紧急停止 [ESTOP]】、串口打开/关闭、3D 姿态归零、清空日志始终保持有效可用；
  - **仪表数据显示不受影响**：锁定期间，角度、转速、IMU 与波形数据仍正常刷新显示。
- **终端指令级拦截 (`action_send_custom_cmd`)**：
  - 若用户在底部终端输入 `M ...`, `EN ...`, `MODE ...`, `ALIGN`, `PID ...` 等电机致动指令，且 `self_test_passed == False`，立即拦截并在终端和状态栏提示：“⚠️ 互锁保护：操作已拦截！必须先执行并通过硬件自检后方可控制电机。”

## 三、文件修改清单

1. **`无刷闭环联调/Core/Src/main.c`**：
   - 移除 `main()` 中上电调用的 `Motor_Encoder_OpenLoop_SelfTest()` 与开机 5 秒延时；
   - 在 `Motor_Encoder_OpenLoop_SelfTest()` 中输出结构化 `$TEST_STEP` 和 `$TEST_REPORT` 报文，并更新通过后的零位对齐逻辑；
   - 保持 `commander_run()` 对 `TEST`/`CHECK` 串口命令的响应。
2. **`无刷闭环联调/UpperComputer/main.py`**：
   - 在 `SerialWorker` 中增加 `$TEST_STEP` 和 `$TEST_REPORT` 的接收与信号发射；
   - 在 `MotorControlCard` 中增加 `set_operable(self, bool)` 方法；
   - 创建 `SelfTestCard` 控件类并整合到主窗口左面板顶部；
   - 实现 `set_motor_controls_locked(self, bool)` 互锁控制逻辑；
   - 在主窗口各动作函数和 `action_send_custom_cmd` 中实施互锁检测拦截；
   - 关联串口连接、断开、自检开始与自检结果事件。

## 四、验证方案

1. **固件编译验证**：
   - 使用 Keil MDK-ARM 5 命令行编译 `CubeMX.uvprojx`，确保 0 Error, 0 Warning，生成最新 `.hex`。
2. **上位机启动与互锁逻辑测试**：
   - 启动 Python 脚本 `python UpperComputer/main.py`，检查 UI 是否正常渲染 `SelfTestCard`；
   - 验证初始未自检状态下，电机滑条与使能控件是否被正确置灰锁定；
   - 验证终端输入 `M 5 0 0` 时是否被互锁成功拦截并给出醒目黄色警告；
   - 模拟自检指令下发与数据接收，验证各个状态徽章与结果展示是否符合预期。
