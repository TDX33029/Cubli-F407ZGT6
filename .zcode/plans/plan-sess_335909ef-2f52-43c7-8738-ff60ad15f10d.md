# 上位机修改与 3D 姿态立方体集成方案

## 1. 现状与问题定位

1. **无用 Emoji 清理**：
   - 移除现有界面中的所有 Emoji/特殊符号（如 `● 未连接`、`⚠ 紧急停止 (ESTOP)` 等），替换为简洁工控风格的文本指示（如 `[未连接]`、`[已连接]`、`[ESTOP 紧急停止]`）或 Qt 原生彩色状态圆点。
2. **电机转速曲线不显示的原因**：
   - **X 轴坐标系漂移**：`now = data['time'] - self.start_time` 采用绝对时间秒数，上位机未配置滚动时间窗（Rolling Window）；当用户无意拖动/点击图表后，pyqtgraph 会永久锁定当前视野在 `[0, 1]`，而实际数据已在数十秒开外，导致曲线跑出视口。
   - **全零数据重合与 Y 轴塌陷**：当三轴目标转速初始均为 0 时，三条细线完全重叠在 Y=0 的深色背景网格线上，且 Y 轴极值差为 0，若未锁定量程会导致画面看起来“空白无曲线”。
3. **三维立方体（3D Cubli Cube）技术选型**：
   - Python 3.14 环境中未安装 `PyOpenGL`，若强行引入 OpenGL 会面临驱动崩溃与缺少轮子的风险。
   - 采用 **基于 PyQt5 原生 `QPainter` 的高性能三维透视投影引擎**：零外部依赖，100% 保证在任意 Windows 系统上稳定以 60 FPS 流畅渲染；支持 3D 欧拉角/四元数旋转矩阵、面深度排序（画家算法）、光照着色、面文字标号（TOP / BOTTOM / M1 / M2 / M3）与鼠标拖拽视角。

## 3. 核心功能实现细节

### 3.1 电机转速曲线彻底修复与体验升级
- **引入示波器式动态滚动时间窗（Rolling Window）**：
  - 数据点采用固定滑动窗口（默认最近 10 秒）。
  - 在 `update_plots()` 中显式锁定 X 轴为 `[t_max - 10, t_max]`，并在 X 轴不足 10 秒时自动填充 `[0, 10]`，确保波形永远在可视区域内稳定向左平滑推进。
- **固化 Y 轴安全量程与防塌陷保护**：
  - 默认将 Y 轴量程设为 `[-25, +25] rad/s`，提供明显的虚线零位基准线。
  - 加粗曲线笔触（宽度 2.5px），M1（亮青）、M2（明橙）、M3（洋红）三色对比分明。
  - 无论电机处于静止（0 rad/s）还是动态调速，曲线均清晰可辨。

### 3.2 姿态解算引擎（IMU 互补滤波）
- **传感器数据源**：
  - 固件以 20Hz 实时上报 LSM6DSRTR 六轴数据：角速度 `Gx, Gy, Gz`（$^{\circ}/\text{s}$）与加速度 `Ax, Ay, Az`（$g$）。
- **默认姿态（水平朝上）**：
  - 静止水平放置时，$A_z \approx +1.0g$，$A_x \approx 0$，$A_y \approx 0$。
  - 加速度计静态姿态：
    $$\text{Pitch}_{acc} = \text{atan2}(A_x, \sqrt{A_y^2 + A_z^2}) \times \frac{180^\circ}{\pi}$$
    $$\text{Roll}_{acc} = \text{atan2}(A_y, A_z) \times \frac{180^\circ}{\pi}$$
- **互补滤波算法**：
  $$\text{Pitch} = 0.95 \times (\text{Pitch} + G_y \times \Delta t) + 0.05 \times \text{Pitch}_{acc}$$
  $$\text{Roll} = 0.95 \times (\text{Roll} + G_x \times \Delta t) + 0.05 \times \text{Roll}_{acc}$$
  $$\text{Yaw} = \text{Yaw} + G_z \times \Delta t$$
- 顶部增加 `[重置姿态]` 按钮，一键将当前静态角度置为初始水平参考零点。

### 3.3 3D Cubli 立方体组件 (`Cubli3DWidget`)
- **几何与物理对应**：
  - 构造三维立方体（8 顶点、6 面），长宽高严格等比。
  - **顶面 (Top, +Z)**：标有 `M3 (Top)`，对应电机 3。
  - **前侧面 (Front, +Y)**：标有 `M2 (Front)`，对应电机 2。
  - **右侧面 (Right, +X)**：标有 `M1 (Right)`，对应电机 1。
  - **底面 (Bottom, -Z)**：触地接触角/面。
- **渲染特效**：
  - **3D 透视投影**：随视距产生自然的近大远小透视感。
  - **面明暗光照**：根据面法向量与平行光夹角动态调整面颜色明暗度。
  - **三维坐标轴**：在立方体中心绘制 X(红)/Y(绿)/Z(蓝) 空间指向箭头。
  - **地面投影与阴影**：在下方绘制轻量化地面网格，强化空间姿态感。
  - **飞轮旋转动量轮动画**：在各面上绘制飞轮圆盘，随着各轴电机的实际转速动态旋转。
  - **交互支持**：支持鼠标左键拖拽调整观察者视角，双击恢复默认正等侧视角。

### 3.4 界面无用 Emoji 清除
- 将所有 `●`、`⚠` 等特殊符号替换为规范的标准文本与 CSS 颜色标签。
