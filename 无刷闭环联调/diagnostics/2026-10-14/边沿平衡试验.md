# 2026-10-14 单边沿平衡调试记录

## 当前已确认与尚未确认的事项

M4对应程序M1/TIM1/ENC3，7极对数。用户选择与该电机轴平行的支撑棱。15秒失能手动倾斜记录中，Gy标准差约4.95°/s，Gx/Gz约0.23/0.27°/s，因此M1的实际旋转轴为IMU Y，使用`BAXIS1 2`。此前默认M1→X不适合本机安装。

用户给出的六面布置：1号面为主板，IMU正面朝外；2号面为M3；3号面为M1；6号面为M2。本轮没有把其他两台的轴和机架方向标记为已确认。机体姿态由IMU取得，飞轮位置由MT6701取得；本轮轴映射结果不能用来断言所有位置显示或编码器都已正确。

**恢复力矩方向仍未可靠确认，自由平衡尚未成功验证。** 早期手扶弱脉冲得到的−1判断、之后因现场感受改成+1的判断均不能作为最终安装方向。用户最新明确表示反作用太小，先前感受可能受到串口等线材影响，撤回此前方向结论。下一步采用物理限位，保留绕支撑棱的小角度摆动，放松线材后用更明显的短时正反对称脉冲重新测方向，再整定增益。不得照抄历史试验中的BDIR作为已验证配置。

## 已实现并实机运行的流程

当前烧录固件：`Cubli-ST/MDK-ARM/CubeMX-edge-waitpose-wide/CubeMX.hex`，ST-LINK下载后已校验。ASCII留档`.codex-debug/20261014/edge_waitpose_wide_i2c.hex`。正交备用构建`CubeMX-edge-waitpose-wide-quad/CubeMX.hex`已编译，未烧录。

1. 静止校准IMU。手扶晃动会令校准重新计数，实测应放在桌面静止后执行。
2. 对所用电机重新对齐，仅确认该轴的BAXIS与机架方向。`BAXIS1 2`和`BDIR1 +/-1`只确认M1，其他轴不会被顺带解锁。
3. 手扶到真实平衡点，以`BZERO`采集一次固定目标；程序不会自动追随之后的偏移姿态。
4. `BSTART 8`进入失能等待。进入目标±10°附近、短时低角速度后开始8秒倒计时。倒计时期间离开窗口即取消并回到等待；小幅晃动不再直接取消。
5. 倒计时末尾，需处于约±3°内且角速度低于0.2rad/s持续至少0.5秒，随后才接管。`BCAP 2..10`可在失能时调整入位窗口。
6. 实际运行后，选定边沿误差或完整重力姿态偏差超过15°、机体角速度超过3rad/s、传感器/心跳/采样过期等会失能。跌倒锁存，不会自动再次运行；明确重新启动才可复位。

灯光：PG5为倒计时（末秒快闪），PG6为实际运行，PG7为跌倒/故障停机，PG8窗口内闪烁表示需进一步靠近或扶稳，常亮表示接近目标且角速度较低。用户要求的“离位取消→回归重新计时”已在第四次实机试验观察到多次5/6状态转换，当时始终失能。最新固件将入位窗口扩大为10°，并将倒计时取消条件与末尾接管稳定条件分开。

边沿控制仍是电压域状态反馈，缺少有效相电流反馈。短时限位试验不能替代实际动力学识别或证明自由平衡稳定。

## 阶段试验

全部通过COM9/115200操作，M2和M3始终失能。每次脚本结束均发送STOP、恢复限压2.5V/速度上限15并释放串口。RAM配置掉电失效。

| 记录 | 条件与结果 |
| --- | --- |
| `edge_pose_identification.jsonl` | 失能15秒手动倾斜，确认M1对应IMU Y |
| `edge_direction_probe_held*` | ±5rad/s、ACC100、1V弱脉冲；手扶反应较小，方向推断已撤回 |
| `edge_first_held_trial*` | −1方向，1.5V，增益20/1.2/0.02/0；扶持运行5秒，约2°误差后主动STOP；不是自由平衡证明 |
| `edge_second_held_trial*` | 未持续进入保存目标的5°窗口，未使能，超时STOP |
| `edge_third_held_trial*` | −1方向，运行约7.6秒后超过脚本40rad/s观察界限而停机 |
| `edge_fourth_held_trial*` | 多次入位、倒计时、离位回等候，未进入运行；暴露5°窗口与晃动条件过于敏感 |
| `edge_wide_fifth_held_trial*` | 最新10°流程，−1方向，运行约2.6秒，达到55rad/s脚本界限；1.5V饱和，未稳住 |
| `edge_sixth_direction_corrected*` | 改+1后机体仍平放，保持失能等待，超时STOP |
| `edge_seventh_direction_corrected*` | +1方向，运行约9.1秒，达到脚本8°倾角观察界限而停机；不能据此证明方向正确 |

早期工作模式FAST名义100Hz与状态帧共同占用115200带宽，存在串口队列延迟；最新版本改为工作模式FAST约50Hz，调试模式仍约100Hz。所有控制/保护在MCU上执行，脚本界限是额外台架限制。主机先于15°固件保护停机的试验不能记成“固件跌倒保护已实机触发”；该保护已通过生产C回归，真实受控倾斜触发尚待核对。
