# 单边 M1 自动平衡操作

M4（用户称呼）就是程序里的 M1。下面流程使用已验证的M1轮轴、方向、49°参考及控制参数。

1. 连接串口：选择COM9、115200，点击“打开串口”。
2. 如果刚上电或复位：选择“调试模式”，在“自检/对齐M1”下点击“开始硬件自检”；通过后切到“工作模式（平衡）”，让机体静止，再点击“静止校准IMU”。已完成自检和校准时可以跳过这一步。
3. 在“单边平衡检测与自动运行”区域点击“加载已验证M1配置（失能）”，等待状态栏提示“配置已回读确认”。这一步恢复M1→IMU Y、方向−1、49°参考、80/5/−0.045/0、6V、330rad/s硬上限、20°倾倒保护及250rad/s满速阈值，电机保持失能。
4. 点击“启动自动单边（无固定时长）”。扶机体到参考附近，PG8提示姿态接近目标。满足约±3°、低角速度、飞轮低于5rad/s并稳定1秒后，PG5开始8秒倒计时。保持到PG6亮，立即完全松手，不用等电机先把机体托稳。
5. 运行没有固定结束时间。倾角超过±20°，或连续达到250rad/s超过3秒，会失能并自动等待；飞轮停止且重新入位后再完整倒计时。需要结束时点击“停止自动单边并失能”；“紧急停止”随时可用。

急停、断连、传感器或硬件故障会退出自动模式；恢复后重新点击启动。上位机需保持连接，为固件提供心跳。

日常测试用“加载已验证M1配置”即可恢复参数。修改“轮轴对应”会清空平衡参考；若误操作导致不能启动，再加载一次配置。其他支撑棱或机械安装改变后，需要重新验证参考姿态。

若加载按钮灰色，先检查M1自检和IMU校准是否完成；若启动按钮灰色，检查参考、轮轴和方向是否确认，以及速度上限是否大于满速阈值。当前检测区会显示原因和保护状态。
