# Cubli 上位机：三电机调试与平衡工作模式

当前版本配套 `../Cubli-ST` 固件，需支持 `$STATE` 状态帧。旧板通过 USART2 (PD5/PD6) 与电脑直连，不需要 ESP32。

## 启动与连接

安装 `requirements.txt` 后运行 `python main.py`，或运行 `run_upper_computer.bat`。

串口设置为 115200/8N1，连接 PD5(TX)、PD6(RX)、GND，上位机选择对应串口。切换上位机的链路下拉框不会改变单片机的物理通信口。

上位机每250ms发送一次 `PING`。STM32 超过1500ms未收到心跳时失能电机。自写串口工具也必须持续发送心跳。正常关闭程序/断开连接会发送STOP；无线桥断开客户端也会发送STOP。

## 调试模式：三轴独立控制

1. 连接后默认进入调试模式，所有驱动保持失能。旧板使用 USART2 (PD5/PD6) 连接电脑，不依赖 ESP32。
2. 选择“自检/对齐 M1/M2/M3”，逐轴执行硬件自检；先识别映射，再正反向扫描电周期、核验极对数和静止零位，约6秒，结束后保持失能。
3. 通过自检的各轴卡片会同时显示。分别选择闭环调速、独立使能，并设置各自目标速度；未通过自检的轴保持锁定。M1/M2/M3 的编码器对应关系由固件自检识别，不按固定编号假设。
4. 停止、切换调试轴、切换开闭环或切换运行模式，都清除目标并失能。急停后点击“复位停机锁存（保持失能）”，再明确使能并设置速度。
5. PID 和平衡增益只允许在失能状态下修改。默认启动为闭环且失能；所有正常使能均需先完成该轴自检。开环仅限低速调试，默认不超过10 rad/s、100 rad/s²，快速变速使用闭环。

自检通过表示映射、正反向跟随与配置极对数核验通过，并完成静止电角度对齐，不代表已完成电流、温升或转速性能测试。电机与编码器的映射由固件自检识别。

## 工作模式：平衡

1. 在调试模式分别自检/对齐需要使用的轴。边沿平衡只要求选中的一轴；顶点平衡要求三轴全部对齐。上电后需重新执行。
2. 切换“工作模式（平衡）”，选择边沿 M1/M2/M3 或顶点（三轴）。切换过程失能全部电机。
3. 将机体保持静止，点击“静止校准 IMU”。连续200个静止样本完成校准；运动会重置计数。校准结束保持失能。
4. 在“轮轴对应”中核实每个电机对应的IMU X/Y/Z轴，点击确认（BAXIS），再核实并设置机架方向BDIR。默认轴/方向未明确确认时禁止启动。随后扶住机体，将其放在真实边沿/顶点平衡姿态，点击“采集当前平衡姿态”。这是目标重力方向；不能用平放桌面的姿态代替顶点平衡点。
5. 按实际机械安装设置 M1/M2/M3 机架方向，并设置所选平衡模式的各轴增益。参数读取按钮回读当前轴；下发增益、设置方向会先失能。
6. “启动平衡”先等待约3°接管窗口、低角速度保持100ms后才使能；也可使用下述8秒倒计时入位流程。姿态偏差超过配置阈值（当前默认20°）、编码器掉线、IMU失效/过期、驱动故障、超速或持续堵转时停机。跌倒保护不会自动重启，重新扶正后需再次点击启动。
7. “停止平衡”或急停会关闭全部驱动；返回调试模式不会恢复历史速度。

**坐标约定必须核实**：控制器要求三台轮轴正交，并用BAXIS明确各轮轴对应IMU X/Y/Z；初始X/Y/Z只是待确认的默认值。机架方向 +1 表示正 Uq 对应飞轮沿该机体轴正转；-1 表示反转。此方向与自动识别的编码器 `sensor_direction` 不同。`BDIR` 只能改变正负方向，不能纠正轴顺序、非正交安装或 IMU 安装旋转，后者需先核实机械/IMU安装；BAXIS只支持正交轴的排列，不能代替任意旋转矩阵。

当前为电压域状态反馈框架，沿用的默认增益没有根据本机质量、惯量、重心和电机参数求解 Riccati 方程，不能直接视为已整定的最优LQR。飞轮反馈系数允许有符号调整；其稳定性需要结合实际动力学确认。软件具备平衡控制流程，实际稳定平衡尚未实机验证。

## 常用协议

每条 ASCII 命令以换行结束；状态由 `$STATE,...#` 回读，遥测为 `$TELE,...#`。

| 命令 | 功能 |
| --- | --- |
| `PING` | 更新心跳，不产生逐条日志应答 |
| `APP 0` / `APP 1` | 调试/工作模式；先清零失能，可复位停机锁存 |
| `DBG 1..3` | 选择自检/对齐轴；清零失能 |
| `TEST [1..3]` / `ALIGN [1..3]` | 对选中/指定单轴自检与电角度对齐 |
| `MODE 0` / `MODE 1` | 调试开环/闭环；切换时失能 |
| `EN2 1` / `M2 -3.0` | 独立使能/调速M2；M1/M3同理，闭环要求该轴已对齐 |
| `M 10 -10 0` | 分别设置 M1/M2/M3 目标速度，可同时运行 |
| `ACC 400` | 设置速度目标斜率，范围100～1500 rad/s²，失能时生效 |
| `STOP` | 全部失能，清空待执行指令，锁存停机 |
| `PP?` / `PP2 7` | 查询/设置逐轴极对数，修改后该轴需重新对齐 |
| `FREQ 1` / `FREQ?` | 重置/回读各轴采样率、最大采样间隔、读取耗时、错误计数 |
| `FAST 5` / `FAST 0` | 紧凑M1/M3流 / 恢复普通遥测；调试约100Hz，工作模式约50Hz，避免状态帧挤占串口带宽 |
| `PID2?` / `PID2 0.2 1.5 0` | 查询/设置M2速度PID |
| `TF2 0.012` | M2测速低通时间常数，0.001～0.1秒 |
| `BMODE 1..4` | M1/M2/M3边沿或三轴顶点；切换时失能 |
| `CAL_IMU` / `BZERO` | 静止校准/采集当前模式目标重力方向；都不会启动平衡 |
| `BAXIS 1 2 3` | 设置轮轴到IMU X=1/Y=2/Z=3的排列，需实际核实；设置后重新确认BDIR、采集BZERO |
| `BDIR 1 -1 1` | 三个机架安装方向；操作时失能 |
| `BAXIS1 2` / `BDIR1 -1` | 只确认M1对应IMU Y轴/机架方向；不会将未测的M2、M3标记为已确认 |
| `BCAP 10` | 失能时设置自动入位窗口，范围±2～±10°；实际接管仍需约±3°并扶稳 |
| `BTRIP 20` | 失能时设置姿态停机阈值，10～60°；默认20°，限位台架可按需设置60°，不取消其他保护；停机阈值不代表能从该倾角恢复 |
| `BREF gx gy gz` | 失能且IMU/轴/方向已确认时恢复此前保存的单位重力参考，避免把重启后的限位端点当作新零点 |
| `BSTART 8` | 边沿模式等待进入已采集的目标窗口，倒计时8秒；离位取消并等待再次入位 |
| `LQR2?` / `LQR2 32 2.4 0.08 0.008` | 当前边沿/顶点参数组的M2增益，顺序为倾角、机体角速度、飞轮速度、飞轮速度积分 |
| `ZERO2 0.3` | 边沿M2的相对目标偏置，单位度；顶点使用BZERO |
| `BU 3` / `U 5` / `L 180` | 平衡输出限压/全局限压/速度上限（可配至360 rad/s；默认180，调速输入仍为±180；限位平衡试验可单独放宽轮速保护） |
| `BAL 1` / `BAL 0` | 显式启动平衡/全部失能 |
| `ENC?` | 失能时回读I2C/正交方法、各轴CPR、原始计数和角度；正交Ready仅代表计数器可用 |
| `STATE?` / `ATT` | 模式、校准、使能、故障、控制倾角与Uq回读 |
| `SENSOR 1` / `SENSOR 2` | 停机后重新初始化主用LSM6DSR/备用MPU6050；原IMU校准失效 |

状态停机码：0正常、1急停、2心跳超时、3驱动故障/使能条件失败、4接收队列溢出、5主循环超过30ms未更新、6电机传感器/非法输出、7持续堵转、8运行中编码器超过5ms未更新。平衡跌倒或IMU保护还会通过 `Bal:4` 表示。

参数、对齐结果、平衡姿态和方向只保存在RAM，掉电后恢复默认。未接入有效相电流反馈，Uq是控制电压而非实测电流；软件保护不能代替驱动器硬件保护或电源限流。

## F4硬件正交编码器

默认HEX仍使用I2C。执行 `python .\Cubli-ST\build_firmware.py --encoder quad`，或将 `Hardware/enc_quad.h` 中 `ENC_USE_HW_QUAD` 设为1并完整重编译，即可使用TIM2/TIM5/TIM8。命令行正交版独立输出在 `MDK-ARM/CubeMX-quad/CubeMX.hex`。公共PPR宏为 `ENC_QUAD_PPR=1024U`，四倍频后CPR=4096，支持 `ENC_QUAD_PPR_M1/M2/M3` 分轴覆盖；宏不修改模块本身的配置。详细接线、测试结果和板上确认步骤见上一级 `F4硬件正交编码器检查说明.md`。

## 2026-10-14 实机整定与当前限制

用户称侧面第一台电机为M4，它对应程序M1/TIM1；顶层电机为程序M3。两台已在12V供电、2.5V限压下完成±10 rad/s与100ms间隔变向测试，参数固化为P=0.30、I=0.80、D=0、Tf=4ms、摩擦前馈0.12V、反电势前馈0.024 V/(rad/s)。M2未通过新对齐扫描且有严重过热史，保留旧参数、正常使能锁定，待硬件检查。

后续高转速实测：单轴短时达到±180rad/s，双轴±120稳速通过；双轴150～180存在M3负向饱和和跟随不足。见 `diagnostics/2026-10-14/高转速实测与M2迁移.md`，不能将可设置180等同于整个范围已稳定。

当前边沿流程文件为 `Cubli-ST/MDK-ARM/CubeMX-edge-trip20/CubeMX.hex`，包含20°姿态停机阈值及定时力矩探测。当前仅M1完成本轮对齐，未自检轴的映射是初始化占位值；原电机诊断及入位流程HEX作为此前阶段留档。

## 手扶入位与指示灯

本机没有主动起立/刹车机构，需要先手扶到实际支撑棱的平衡点，采集一次BZERO。之后“等待入位，8秒倒计时后启动”按钮只观察这个固定目标，不会跟着每次晃动改变零点。

- PG5：±10°入位后慢闪倒计时，最后1秒快闪；离开窗口时熄灭并返回等待，电机保持失能。
- PG8：窗口内闪烁表示需要靠近或减小晃动；接近目标约±3°且角速度较低时常亮。倒计时末尾需满足该条件至少0.5秒才接管，否则继续等待入位。
- PG6：实际平衡控制正在运行。
- PG7：跌倒/故障停机。实际运行后跌倒锁存，不会自行再启动，需要明确重新启动。

M4对应程序M1，围绕其支撑棱手动倾斜的实测旋转轴为IMU Y，因此本轮使用`BAXIS1 2`。**恢复方向尚未确认**：用户认为反作用太小、线材可能干扰，已撤回先前方向感受，因此历史试验的−1和+1都不能当作已验证安装方向，需物理限位后重新测量。机体姿态来自IMU，飞轮角度来自MT6701，两者不能混为一项“位置”。状态中的AxisMask/DirMask表示指令明确确认过的轴；仅M1确认时均为1，不能据此启动三轴顶点平衡。

扶持试验使用U/BU=1.5V，状态反馈20/1.2/0.02/0（倾角、机体角速度、飞轮速度、飞轮积分），属于初始试验参数，尚未证明自由平衡稳定。跌倒保护同时检查选定边沿倾角和完整重力姿态变化，包含偏离支撑轴方向的跌倒。具体实测与结束状态见 `diagnostics/2026-10-14/边沿平衡试验.md`。

物理限位下可用`BPROBE 2 60`对当前边沿轴输出2V、60ms定时脉冲。必须在工作模式、失能、该轴已对齐、轮轴已确认、IMU校准有效时执行；不要求先猜机架方向。范围为±6V、20～120ms，其中超过3V时最长80ms，并且不超过U限压。F4快速电机循环自行结束脉冲并失能，机体相对移动10°/角速度2rad/s/飞轮60rad/s以及原有保护仍会提前中止。探测时FAST约100Hz，附带三轴机体角速度；Bal=7表示探测中。此命令用于有物理约束的安装方向识别。

最新构建`CubeMX-edge-handover/CubeMX.hex`加入接管过渡：机体PD立即生效，飞轮反馈延后0.5秒、再用1秒渐入；Angle为有符号倾角。此版本因CH340/ST-LINK断开尚未烧录，不能把它的回归结果当作板上已经实测。板上最后确认仍是上述20°阈值版本。


手扶接管试验：扶在参考附近保持至PG6亮，然后立即完全松手，手留在旁边保护，不要等待电机先把机体托稳。飞轮的机体反作用力矩来自加减速；手扶时反力被手承担，飞轮匀速旋转也不代表仍有恢复力矩。触碰限位、线材承重、手扶回正的记录不能作为自由平衡通过。60°/300rad/s为限位台架试验设置，既不代表恢复范围，也不代表全范围稳定；设备上电默认仍20°/180rad/s。
