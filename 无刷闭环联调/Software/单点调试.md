# 三轴单点调试

当前三轴电机均已修复。安装映射实测为M1→IMU Y、M2→IMU Z、M3→IMU X，机体方向均为−1；编码器对应ENC3/ENC1/ENC2，均7极对、编码器方向+1。机体方向与编码器方向是不同参数。电池牢固固定在机体上，改变电池位置后需要重新验证参考。

M2已完成8秒/15秒单边试验，M3已完成3秒/8秒单边试验。单点第一轮触发M2轮速100rad/s主机保护，尚未验证单点稳定。

新版固件通过STATE中的`CornerStart:1`声明支持单点灯光倒计时、保存参考加载和完整FAST姿态。上位机选择“工作模式→顶点（三轴）”后，仅在固件支持且三轴对齐、IMU校准、映射/方向/参考有效时解锁单点倒计时按钮。PG5倒计时，PG6实际接管；PG6亮即松手。离开入位范围会取消倒计时。

单点自动模式已启用（固件`CubeMX-corner-auto`，需配合新版上位机）。上位机“单边/单点平衡检测与自动运行”区内新增“加载已验证单点配置（失能）”：恢复23.44°/50°参考、轴映射2/3/1、方向−1/−1/−1、三轴80/5/−0.030/0、BYAW 3、U/BU 6V、L330、20°停机和250rad/s满速阈值。加载成功须收到BREF应答及匹配的新状态帧。加载本身不使能电机。

点击“启动自动单点（无固定时长）”（等价于`BAUTO 1 8`）后，固件持续检测入位，没有固定运行时长：三轴全部对齐且传感器有效、参考有效、总倾角小于3°、机体角速度低于0.2rad/s、三只飞轮均低于5rad/s，连续稳定1秒后开始8秒倒计时；离开条件会取消倒计时。PG6亮后立即松手。任一轴超过±20°立即失能并等待下次入位；任一轮达到满速阈值（默认250rad/s）持续3秒同样失能等待，低于阈值就清零计时。重试至少冷却1秒，且必须等三只飞轮降到5rad/s以下，再重新满足稳定入位及完整倒计时。超过L330的硬超速、机体角速度/传感器故障、急停和通信超时锁停并退出自动模式，不会自行恢复。

当前应先使用限时试验脚本调试：

```powershell
python diagnostics/serial_corner_trial.py --port COM7 --tag NEW_UNIQUE_TAG --expected-pose diagnostics/2026-10-14/repaired_corner_hand_pose_still_summary.json --body-axes 2 3 1 --directions -1 -1 -1 --seconds 3 --voltage 3.5 --wheel-bound 100
```

脚本回读三轴状态、等待手扶姿态静止后采集BZERO；新固件使用MCU的8秒倒计时，旧固件保留主机等待方案。首次采用3.5V、3秒，主机检查任一轮速100rad/s、总倾角10°、总角速度1.5rad/s，固件硬轮速120rad/s、倾倒20°。退出时必发STOP并确认三轴失能。

已记录准确参考重力向量时，可追加`--reference-gravity gx gy gz`，通过BREF加载固定目标，避免每次手扶位置变化导致参考漂移。该参数仅适用于新固件；候选参考不等于已验证的重心中性点。`--prepare-only`只配置并采集参考，不使能平衡。

独立自转阻尼命令为`BYAW 0..10`，仅在失能时接受。STATE中的`YawTune:1`表示支持，`YawD`回读当前值；新版默认3.0。脚本可用`--yaw-damping 3`设置并回读确认。此参数控制绕重力竖直轴的转动，独立于三轴姿态D增益；不能用增大倾倒或角速度保护来替代调参。

## 长期单点自动测试

长时间无人值守测试使用`diagnostics/serial_corner_auto.py`。脚本自动配置并回读全部参数、加载固定参考、发送`BAUTO 1 8`，然后记录每一次平衡尝试（时长、保护原因、最大倾角、各轮最大轮速）并容忍自动重入；保护后无需手工重启。主机保护阈值都高于固件阈值（轮速360、倾角28°、角速度4rad/s），只在固件保护失效时才动作。Ctrl+C或错误退出时必发STOP、FAST 0、恢复U2.5/L15并确认三轴失能。

```powershell
python diagnostics/serial_corner_auto.py --port COM7 --tag corner_auto_YYYYMMDD --live-state live_pose.json
```

默认无限时长，可用`--duration-minutes`限制；`--capture-pose`改用BZERO现场采集（默认使用已验证固定参考）。输出jsonl与summary到`diagnostics/2026-10-15/`。设备硬故障（Bal=4）会终止脚本，需要重新自检、校准并重新加载配置后再次启动。

电机重新自检后，该轴的机体方向确认及其边沿参考、单点参考会失效；须确认安装方向并重新加载参考。掉电/复位后仍需重新对齐和静止校准。单边已验证参数和历次记录见`diagnostics/2026-10-14/三轴修复后复检.md`。

2026-10-15 更新：全部轮次分析显示各次均以飞轮动量缓慢积累结束（历史最好13.7s）。脚本默认增益已调整为`80/5/0/0`（Kw原−0.030；正Kw在实机1.4s速倒，硬件禁用），BTRIM默认0。参考方向支持定点迭代：`python diagnostics/analyze_corner_windup.py --settle`会打印候选`--reference-gravity`（取各轮稳定姿态均值，2–3轮收敛到真实重心中性），配合`serial_corner_auto.py --reference-gravity gx gy gz`使用。完整分析、下一轮流程与开放问题见`单点长期平衡联调说明.md`；闭环增益模型与扫描见`diagnostics/corner_loop_model.py`。新固件支持BTRIM倾角误差积分（STATE`TrimTune:1`），验证代码时可用`--tilt-trim 2`开启，当前默认关闭。

## 实时入位提示

`Software/pose_monitor.py`只读取姿态文件，显示当前角度、候选目标、2°入位圈和三只飞轮转速，不占用串口。调试脚本可通过`--live-state FILE.json`输出实时姿态；窗口通过`--live-file FILE.json --capture-file CANDIDATE.json`读取。数据超过1秒未更新时显示暂停，避免把旧姿态当成当前值。

“记录当前姿态为候选”只保存当前重力向量，不启动电机；仅在实时、失能状态下可用。手扶力最小位置仍是候选，需要自由响应验证。单点脚本将入位窗口设为2°，减少偏角较大时接管造成的轮速积累。
